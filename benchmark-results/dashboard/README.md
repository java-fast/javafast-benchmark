# JavaFast benchmark dashboard template

The dashboard expects the merged JSON generated by `MergeBenchmarkResultsTask` at:

`benchmark-results/dashboard/data/<SimulationName>.json`

Open a simulation with:

`index.html?simulation=HelloWorldSimulation`

README link example:

```markdown
[View benchmark results](../../benchmark-results/dashboard/index.html?simulation=HelloWorldSimulation)
```

## Run locally

Browsers usually block `fetch()` from `file://`. Serve this directory through any local static HTTP server,
or use your IDE's built-in web preview. The benchmark extraction and aggregation pipeline itself remains
Gradle/Groovy-only.
